# Customer Sales Exploratory Data Analysis using Python

## Project Overview
Performed Exploratory Data Analysis (EDA) on customer sales data using Python to identify sales trends, customer demographics, and product performance. The project focuses on data cleaning, visualization, and generating business insights from customer purchasing behavior.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Features
- Cleaned and preprocessed raw sales data.
- Performed Exploratory Data Analysis (EDA).
- Analyzed customer demographics and purchasing patterns.
- Created visualizations using bar charts and pie charts.
- Identified top-performing product categories and sales trends.

## Skills Demonstrated
Data Cleaning | EDA | Data Visualization | Pandas | NumPy | Matplotlib | Seaborn

## Key Insights
- Analyzed gender-wise sales distribution.
- Evaluated age-group purchasing behavior.
- Identified top-selling product categories.
- Generated insights to support business decision-making.

## Project Files
- Customer_Sales_EDA.ipynb

## Conclusion
This project helped develop practical skills in data cleaning, exploratory data analysis, and visualization using Python for real-world business datasets.
